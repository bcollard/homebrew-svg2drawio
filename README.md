# homebrew-svg2drawio

Homebrew tap for [svg2drawio](https://github.com/bcollard/svg2drawio) — convert
SVG files into native draw.io (mxGraph) diagrams.

```bash
brew tap bcollard/svg2drawio
brew install --cask svg2drawio
```

The cask in `Casks/` is published automatically by goreleaser on every
`vX.Y.Z` tag of the main repository. Do not edit it by hand.
